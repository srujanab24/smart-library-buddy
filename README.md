# 📚 Smart Library Book Retrieval System

A full-stack web application designed to make library book searching fast, simple, and efficient.  
This system allows users to search books, check availability, view rack locations, and get related book recommendations.

> **Academic Mini Project | 2025**

---

## 🚀 Features

- 🔍 **Fast Book Search**  
  Search books instantly by **title, author, or category**.

- ✅ **Availability Tracking**  
  Check whether a book is **available or issued** in real time.

- 📍 **Rack Location Display**  
  View the **exact rack number and shelf** of the book.

- 🤖 **Related Book Recommendations**  
  Get similar book suggestions based on category.

- 🔐 **Admin Dashboard**  
  Admin can add, update, and delete books and manage availability.

- 📱 **Responsive UI**  
  Works smoothly on desktop and mobile devices.
